# Archive — implémentation Android native historique

Ce dossier contient l'ancienne application Kotlin + Jetpack Compose + Room (LOTS 0 à 16).
Elle n'est plus compilée ni maintenue : la stack retenue est désormais React Native + TypeScript + Rust.

Les fichiers sont conservés uniquement comme référence historique des règles métier et des scénarios de test déjà validés.
Voir `docs/ARCHITECTURE_RN_RUST.md` à la racine du dépôt.
